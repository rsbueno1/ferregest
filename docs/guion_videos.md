# Guiones

## Video 1: Scrum Poker (3–5 min)
1. Felix: presenta al equipo, el proyecto y el Objetivo del Sprint.
2. Saviel: muestra Jira (épicas e historias) y lee HU-04.
3. Votación a ciegas, revelación, discusión y consenso, para cada historia.
4. Saviel: muestra las estimaciones registradas en Jira.
5. Felix: cierra con el total de puntos del sprint.

## Video 2: Incremento funcional (4–6 min)
1. Randolph: abre el listado y muestra la búsqueda por nombre y por código.
2. Crear un artículo nuevo; mostrar que aparece en la lista.
3. Intentar crear uno con código repetido; mostrar el aviso de error.
4. Editar el precio del artículo; mostrar el cambio.
5. Aiker: abrir Existencias, ver por almacén y total, ajustar una cantidad.
6. Desactivar el artículo; activar «Mostrar desactivados» para verlo.
7. Aiker: mostrar la base de datos (tablas articulos, almacenes, existencias) y `npm test` en verde.
8. Johnsy: mostrar el repositorio de GitHub y el tablero de Jira con las tareas terminadas.
